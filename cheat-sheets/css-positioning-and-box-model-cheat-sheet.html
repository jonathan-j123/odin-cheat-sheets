CSS Positioning & Box Model Cheat Sheet

1. Position

The position property determines how an element is positioned in the document.

Value Behavior
static Default. The element follows the normal document flow. top, right, bottom, left, and inset do not move it.
relative Stays in the normal flow but can be visually moved using top, right, bottom, left, or inset.
absolute Removed from normal flow and positioned relative to its containing block.
fixed Removed from normal flow and positioned relative to the viewport in the common case. It remains in place while scrolling.
sticky Behaves like a relatively positioned element until a scroll threshold is reached, then sticks within its containing block.
.box { position: relative; }

2. top, right, bottom, left

These properties move a positioned element from a particular edge. They work with elements whose position is not static. 

.box {
  position: relative;
  top: 20px;
  left: 30px;
}
  • top: 20px; → moves the element downward.
  • right: 20px; → moves it toward the left.
  • bottom: 20px; → moves it upward.
  • left: 20px; → moves it toward the right.
Important: These properties do not work as positioning offsets when position: static is used.

3. inset

inset is shorthand for top, right, bottom, and left.

  • inset: 0; → all four sides are 0.
  • inset: 10px; → 10px on all four sides.
  • inset: 10px 20px; → top/bottom = 10px, left/right = 20px.
  • inset: 10px 20px 30px; → top = 10px, left/right = 20px, bottom = 30px.
  • inset: 10px 20px 30px 40px; → top, right, bottom, left.
.box {
  position: absolute;
  inset: 0;
}
The element stretches to the edges of its containing block.

4. z-index

Controls the stacking order of positioned elements and other elements that participate in stacking contexts. 

.box {
  position: relative;
  z-index: 10;
}
  • Higher stacking levels generally appear in front of lower ones.
  • Negative values can place an element behind other content.
  • z-index is affected by stacking contexts.
Think of z-index as controlling the element's front-to-back stacking order.

5. Containing Block

A positioned element needs a reference area for its offsets. This reference area is called its containing block. 

.parent {
  position: relative;
}

.child {
  position: absolute;
  top: 0;
  right: 0;
}

In this common pattern, the absolutely positioned child is positioned relative to the parent.

Common pattern: position: relative on the parent + position: absolute on the child.

6. Margin

margin controls space outside the element. 

.box {
  margin: 20px;
}
  • margin: 20px; → 20px on all sides.
  • margin: 10px 20px; → top/bottom = 10px, left/right = 20px.
  • margin: 10px auto; → 10px top/bottom and automatic left/right margins.
Important: Margins create space outside the border and can affect the position of the element relative to surrounding elements.

7. Padding

padding controls space inside the element, between the content and the border. 

.box {
  padding: 20px;
}

Increasing padding makes the content area farther away from the border.

8. Border

border creates a visible boundary around the padding and content. 

.box {
  border: 5px solid black;
}

The shorthand follows: 

border: width style color;

Example:

border: 2px solid #333;
Margin
Content
Outside → Margin | Border | Padding | Content

9. box-sizing

box-sizing determines how an element's declared width and height are calculated.

content-box

.box {
  box-sizing: content-box;
  width: 200px;
  padding: 20px;
  border: 10px solid black;
}

With content-box, the declared width applies only to the content.

Total width = 200 + 20 + 20 + 10 + 10 = 260px

border-box

.box {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 10px solid black;
}

With border-box, the declared width includes the content, padding, and border.

Total width = 200px

Common reset: 
* {
  box-sizing: border-box;
}
This makes width and height easier to reason about.

10. Width & Height

These properties determine the dimensions of an element's box. 

.box {
  width: 300px;
  height: 150px;
}

Useful related properties:

  • width
  • height
  • min-width
  • max-width
  • min-height
  • max-height
max-width: 100%; is commonly used to prevent an element from becoming wider than its containing block.

11. The CSS Box Model

Every element is represented as a rectangular box consisting of four areas.

Margin
Border
Padding
Content
  • Content → actual text, image, etc.
  • Padding → space inside the element.
  • Border → edge surrounding the padding.
  • Margin → space outside the element.

12. Centering

Absolute positioning + auto margins

.parent {
  position: relative;
}

.child {
  position: absolute;
  inset: 0;
  margin: auto;
  width: 100px;
  height: 100px;
}

This centers a fixed-size absolutely positioned element inside its containing block.

Flexbox

.parent {
  display: flex;
  justify-content: center;
  align-items: center;
}

Flexbox is generally the simpler choice when you just need to center content.

13. Quick Positioning Comparison

Property / Value Main Purpose
position Determines how an element participates in positioning.
top/right/bottom/left Offsets a positioned element from an edge.
inset Shorthand for top, right, bottom, and left.
z-index Controls stacking order within the relevant stacking contexts.
margin Creates space outside the element.
padding Creates space inside the element.
border Creates a boundary around the element.
box-sizing Determines how width and height include padding and border.
width / height Controls the element's dimensions.

14. Mental Model

Think about CSS layout in layers:

  1. Position → Where does the element participate in the layout?
  2. Offsets → How far is it moved from its reference edges?
  3. Dimensions → How wide and tall is it?
  4. Padding → How much space is inside?
  5. Border → Where is the visible edge?
  6. Margin → How much space surrounds it?
  7. z-index → Which element appears in front?
