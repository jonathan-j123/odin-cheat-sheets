🖥️ Command Line Practice Flow

1️⃣ List Files with Classification

ls -F

Shows folders with /, executables with *, and symbolic links with @.

2️⃣ Make Project Folders

mkdir -p my_project/css my_project/js my_project/html

Creates the project folder and all subfolders in one command.

3️⃣ Navigate into the Folder

cd my_project

Moves into the project directory.

4️⃣ Create or Edit Files with Nano

nano css/style.css nano js/script.js nano html/index.html

Opens existing files or creates new files after saving.

5️⃣ Save & Exit Nano

  • Ctrl + O Save file
  • Enter Confirm filename
  • Ctrl + X Exit Nano

6️⃣ Confirm Files Were Created

ls -F

Verify that your folders and files now exist.

7️⃣ Clear the Screen

clear

Clears the visible terminal screen.

clear -x

Clears the screen while preserving scrollback history.

🎯 Practice Goal
Learn how to view files, create folders, navigate directories, edit files with Nano, save your work, and keep your terminal clean.
