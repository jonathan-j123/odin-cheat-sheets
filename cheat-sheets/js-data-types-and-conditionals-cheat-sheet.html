⚡ JavaScript Data Types & Conditionals Cheat Sheet

📊 Data Types

Primitive Types

Type Example Description
string "Hello" Text
number 42, 3.14 Integers and floating-point numbers
bigint 123n Very large integers
boolean true, false Logical true/false value
undefined undefined A variable has not been assigned a value
null null Intentional absence of a value
symbol Symbol("id") Unique identifiers

Non-Primitive / Reference Types

  • Object → { name: "Jonathan", age: 26 }
  • Array → [1, 2, 3]
  • Function → function greet() {}
Important: Arrays and functions are technically objects in JavaScript.

🔍 Type Checking

Expression Result
typeof "hello" "string"
typeof 42 "number"
typeof true "boolean"
typeof undefined "undefined"
typeof null "object"
typeof [] "object"
typeof function() {} "function"
Array.isArray([]) true
Quirk: typeof null returns "object". This is a historical JavaScript bug.

✅ Conditionals

if / else

if (age >= 18) {
  console.log("Adult");
} else {
  console.log("Minor");
}

else if

if (score >= 90) {
  console.log("A");
} else if (score >= 80) {
  console.log("B");
} else {
  console.log("C or below");
}

Nested if

if (isLoggedIn) {
  if (isAdmin) {
    console.log("Welcome, Admin!");
  }
}

🔀 switch

switch (day) {
  case "Monday":
    console.log("Start of week");
    break;

  case "Friday":
    console.log("Weekend soon!");
    break;

  default:
    console.log("Midweek");
}
Remember: break prevents execution from continuing into the next case.

⚡ Logical Operators

Operator Name Example
&& AND true && true → true
|| OR true || false → true
! NOT !true → false 
if (isLoggedIn && isAdmin) {
  console.log("Welcome, Admin!");
}

🧩 Comparison Operators

Operator Meaning
== Loose equality
=== Strict equality
!= Loose inequality
!== Strict inequality
> Greater than
< Less than
>= Greater than or equal to
<= Less than or equal to 
console.log(5 == "5");   // true
console.log(5 === "5");  // false

console.log(10 > 5);     // true
console.log(10 <= 10);   // true
Best practice: Prefer === and !== unless you specifically need type coercion.

🎯 Ternary Operator

Short form of a simple if / else.

let status = age >= 18 ? "Adult" : "Minor";

Equivalent to:

let status;

if (age >= 18) {
  status = "Adult";
} else {
  status = "Minor";
}

🌀 Truthy & Falsy

Falsy Values

false, 0, -0, 0n, "", null, undefined, NaN

Everything else is truthy.

if ("hello") {
  console.log("This runs!");
}

if ([]) {
  console.log("Arrays are truthy!");
}

if ({}) {
  console.log("Objects are truthy!");
}

❓ Nullish Coalescing

?? uses the right-hand value only when the left-hand value is null or undefined. 

let username = userName ?? "Guest";

Unlike ||, it does not treat 0 or "" as missing.

let count = 0;

console.log(count || 10); // 10
console.log(count ?? 10); // 0

🔗 Optional Chaining

?. safely accesses a property that might not exist. 

console.log(user?.address?.city);

If user or address is null or undefined, the result is undefined instead of an error.

📝 Logical Assignment

Operator Meaning
||= Assign if value is falsy
&&= Assign if value is truthy
??= Assign if value is nullish 
let username = "";

username ||= "Guest";

console.log(username); // "Guest"
