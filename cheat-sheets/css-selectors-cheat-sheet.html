CSS Selectors Cheat Sheet

Beginner → Advanced Reference Guide

1. Basic Selectors

Type Selector

p { color: blue; }
Selects all elements of a specific HTML type.

Class Selector

.highlight { background: yellow; }
Selects elements with the specified class.

ID Selector

#header { color: red; }
Selects the element with the specified ID.

Universal Selector

* { margin: 0; }
Selects every element.

Grouping

h1, h2, h3 { color: green; }
Applies the same styles to multiple selectors.

Chaining

p.highlight { color: red; }
Selects elements that match multiple conditions. This selects only <p> elements with the class "highlight".

2. Combinators

Descendant

div p { color: blue; }
Selects every <p> that is anywhere inside a <div>.

Child

div > p { color: blue; }
Selects <p> elements that are direct children of <div>.

Adjacent Sibling

h1 + p { color: blue; }
Selects the first <p> immediately after an <h1>.

General Sibling

h1 ~ p { color: blue; }
Selects all <p> siblings that come after an <h1>.

3. Attribute Selectors

Has Attribute

[disabled]
Selects elements that have the specified attribute.

Exact Attribute

input[type="text"]
Selects elements whose attribute exactly matches the value.

Starts With

a[href^="https"]
Selects elements whose attribute value starts with the specified text.

Ends With

a[href$=".pdf"]
Selects elements whose attribute value ends with the specified text.

Contains

a[href*="example"]
Selects elements whose attribute value contains the specified text.

Word Match

[class~="active"]
Matches an individual word in a space-separated attribute value.

Prefix / Language Match

[lang|="en"]
Matches an attribute value that is exactly "en" or begins with "en-".

4. Pseudo-Classes

:hover

button:hover { background: blue; }
Selects an element when the pointer is over it.

:focus

input:focus { border-color: blue; }
Selects an element when it has focus.

:active

button:active { transform: scale(.98); }
Selects an element while it is being activated.

:visited

a:visited { color: purple; }
Selects links that the user has already visited.

:first-child

li:first-child { font-weight: bold; }
Selects an element if it is the first child of its parent.

:last-child

li:last-child { font-weight: bold; }
Selects an element if it is the last child of its parent.

:nth-child()

li:nth-child(2) { color: red; }
Selects an element based on its position among its siblings.

:nth-child(odd)

li:nth-child(odd) { background: #eee; }
Selects odd-numbered children.

:nth-child(even)

li:nth-child(even) { background: #eee; }
Selects even-numbered children.

:nth-of-type()

p:nth-of-type(2) { color: red; }
Selects an element based on its position among siblings of the same type.

:first-of-type

p:first-of-type { color: blue; }
Selects the first sibling of that element type.

:last-of-type

p:last-of-type { color: blue; }
Selects the last sibling of that element type.

:only-child

p:only-child { color: red; }
Selects an element that is the only child of its parent.

:only-of-type

p:only-of-type { color: red; }
Selects an element that is the only one of its type among its siblings.

:not()

p:not(.special) { color: gray; }
Selects elements that do not match the selector inside the parentheses.

:is()

:is(h1, h2, h3) { color: blue; }
Matches any selector listed inside the parentheses.

:where()

:where(h1, h2, h3) { margin: 0; }
Similar to :is(), but has zero specificity.

:has()

div:has(img) { border: 1px solid; }
Selects an element if it contains an element matching the selector.

:checked

input:checked { accent-color: blue; }
Selects checked checkboxes or radio buttons.

:disabled

button:disabled { opacity: .5; }
Selects disabled form controls.

:enabled

button:enabled { cursor: pointer; }
Selects enabled form controls.

:required

input:required { border: 2px solid; }
Selects form controls with the required attribute.

:valid

input:valid { border-color: green; }
Selects form controls whose current value passes validation.

:invalid

input:invalid { border-color: red; }
Selects form controls whose current value fails validation.

:empty

div:empty { display: none; }
Selects elements that have no children.

:root

:root { --main-color: blue; }
Selects the document's root element, normally <html>.

5. Pseudo-Elements

::before

p::before { content: "→ "; }
Creates a pseudo-element before the element's content.

::after

p::after { content: " ✓"; }
Creates a pseudo-element after the element's content.

::first-letter

p::first-letter { font-size: 2rem; }
Selects the first letter of the element's text.

::first-line

p::first-line { font-weight: bold; }
Selects the first line of text.

::selection

::selection { background: yellow; }
Styles text selected by the user.

::placeholder

input::placeholder { color: gray; }
Styles placeholder text in form controls.

::marker

li::marker { font-weight: bold; }
Styles the marker of list items.

7. Important Notes

Selector vs. Combinator: A selector identifies elements. A combinator describes the relationship between selectors, such as parent, child, or sibling relationships.
Pseudo-class vs. Pseudo-element: A pseudo-class uses one colon, such as :hover or :first-child. A pseudo-element normally uses two colons, such as ::before or ::first-letter.
:nth-child() vs. :nth-of-type(): :nth-child() considers the element's position among all siblings. :nth-of-type() considers its position among siblings of the same element type.
Specificity: In general, ID selectors have greater specificity than class, attribute, and pseudo-class selectors, while type selectors have lower specificity.
