Git Basics Cheat Sheet

A single-column Git reference optimized for studying, screenshots, and PNG export.

⚡ Basic Workflow

git status → git add . → git commit -m "message" → git push
Memory Trick: Check → Stage → Snapshot → Upload

1. Check Git Version

git --version

2. Set Default Branch

git config --global init.defaultBranch main

3. Create Project Directory

cd ~
mkdir repos
cd repos/

4. Clone a Repository

git clone git@github.com:USER-NAME/REPOSITORY-NAME.git
Important: The Odin Project lesson uses SSH.

HTTPS example: https://github.com/USER-NAME/REPOSITORY-NAME.git

5. Check the Remote

git remote -v 
origin git@github.com:USER-NAME/git_test.git (fetch)
origin git@github.com:USER-NAME/git_test.git (push)

6. Create a File

touch hello_world.txt

7. Check Changes

git status

8. Stage Changes

git add hello_world.txt
git add .

9. Commit a Snapshot

git commit -m "Add hello_world.txt"

10. View History

git log

11. Push to GitHub

git push
git push origin main

12. Open in VS Code

code .

Git Syntax

program | action | destination

git add .

git | add | .

git commit -m "message"

git | commit -m | "message"

git status

git | status | (no destination)

Best Practice

Atomic Commits: Keep each commit focused on one feature or task. This makes changes easier to understand, review, and revert.
